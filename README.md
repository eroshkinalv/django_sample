# Проект django_sample

## Описание:

Проект django_sample - это учебный проект на Python, который представляет собой основу для сайта интернет-магазина c использованием фреймворка Django. 

Приложение Каталог:
- Созданы шаблон и контроллер(CBV) для отображения домашней страницы.
- Созданы шаблон и контроллер(CBV) для отображения страницы с контактной информацией.
- Созданы шаблон и контроллер(CBV) для отображения страницы с подробной информацией о товаре.
- Создан общий (базовый) шаблон, который включает общие элементы страницы (такие как шапка, подвал и стили). 
- Для стилизации страниц использован Bootstrap.
- Создан класс формы для продукта.
- Реализованы CRUD-операции для продуктов с помощью форм.
- Реализована валидация на запрещенные слова отдельно для имени и отдельно для описания.
- Добавлена кастомная валидация для поля price.

Приложение Блог:
- Реализован полный CRUD с использованием CBV.
- На уровне контроллеров добавлено: увеличение счетчика просмотров, фильтрация опубликованных статей, перенаправление после редактирования.

Приложение Пользователи:
- Создана форма для регистрации пользователя.
- Создана форма для авторизации пользователя.
